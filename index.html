택배 일괄폼 생성기

쇼핑몰 주문 엑셀을 업로드하면 상품명/옵션/수량을 정리하고, 같은 받는사람 + 전화번호 + 주소 기준으로 묶어 택배 일괄폼을 생성합니다. 옵션/사이즈는 반드시 상품명1에 합쳐집니다.

생성되는 일괄폼 헤더
  • 기본값: 받는사람 / 전화번호1 / 우편번호 / 주소 / 수량(A타입) / 상품명1 / 배송메시지
  • 택배 일괄폼 미리보기 표의 헤더 칸에서 바로 수정/추가/삭제할 수 있고, 각 헤더마다 표시할 정보를 선택할 수 있습니다.
  • 헤더명과 표시 정보 설정은 현재 기기에 자동 저장됩니다.
  • 수량(A타입)은 묶음 1건당 1로 고정됩니다.
  • 옵션/사이즈는 배송메시지가 아니라 상품명1에 붙습니다.
  • 같은 이름이어도 전화번호 또는 주소가 다르면 별도 택배로 분리됩니다.

택배 일괄폼 생성기 사용 방법

이 페이지는 온라인 주문 엑셀을 업로드한 뒤 수령인 정보가 같은 주문을 하나의 택배 건으로 묶어 주는 웹 도구입니다. 상품명, 옵션, 수량을 조합해 택배사 일괄 접수용 엑셀 파일을 만들 수 있습니다.

1. 주문 엑셀 업로드 xlsx, xls, csv 파일을 선택하면 첫 번째 시트의 헤더와 주문 데이터를 브라우저에서 읽습니다.
2. 컬럼 자동 매핑 확인 받는사람, 전화번호, 주소, 상품명, 옵션, 수량, 배송메시지 컬럼을 자동으로 찾고 직접 수정할 수 있습니다.
3. 일괄폼 다운로드 미리보기에서 헤더와 표시 정보를 확인한 뒤 현재 날짜가 포함된 엑셀 파일로 저장합니다.

묶음 처리 기준

받는사람, 전화번호, 주소가 모두 같은 주문은 하나의 택배로 간주합니다. 같은 이름이라도 전화번호나 주소가 다르면 다른 수령 건으로 분리합니다.

상품명 생성 방식

상품명과 옵션/사이즈를 합친 뒤 수량을 EA 단위로 붙입니다. 예를 들어 반팔티 XL 1개와 머플러 2개가 같은 수령인에게 있다면 상품명1에는 반팔티 XL 1EA / 머플러 2EA처럼 표시됩니다.

개인정보 및 파일 처리 안내

업로드한 엑셀 파일은 서버로 전송하지 않고 현재 브라우저 안에서만 처리됩니다. 페이지를 새로고침하거나 브라우저를 닫으면 업로드한 원본 데이터는 이 페이지에 남지 않습니다.

브라우저에 저장되는 정보

  • 일괄폼 미리보기 헤더명
  • 각 헤더의 표시 정보 설정
  • 사용자가 직접 지정한 출력 헤더 구성

위 설정은 사용 편의를 위해 현재 기기의 브라우저 저장소에만 저장됩니다. 수령인 이름, 전화번호, 주소, 주문 상품 데이터는 별도로 저장하지 않습니다.

자주 묻는 질문

엑셀 컬럼명이 쇼핑몰마다 달라도 사용할 수 있나요?

사용할 수 있습니다. 자동 매핑이 틀리면 컬럼 자동 매핑 확인 영역에서 직접 선택하면 됩니다.

옵션이 배송메시지로 들어가면 어떻게 하나요?

옵션/사이즈 컬럼은 상품명1에 합쳐지도록 설계되어 있습니다. 그래도 원본 엑셀의 헤더가 특이한 경우 옵션/사이즈와 배송메시지 매핑을 직접 확인하세요.

헤더를 추가하면 데이터도 같이 나오나요?

헤더를 추가한 뒤 해당 헤더 아래의 표시 정보 선택 박스에서 받는사람, 전화번호, 주소, 상품명1, 배송메시지, 빈값 중 하나를 선택할 수 있습니다.

파일명은 바꿀 수 있나요?

다운로드 영역에서 파일명 중간 문구를 직접 입력할 수 있습니다. 최종 파일명은 날짜_입력값_택배일괄폼.xlsx 형식으로 생성됩니다.
